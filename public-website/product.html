THE PRODUCT

Passwords that stay close to you.

127Vaults is being built for people who want practical control over their password infrastructure, while keeping private vaults across devices.

HOW IT WORKS

Local first.
Encrypted in transit.

Each authorized device is designed to keep an encrypted local copy of vaults it can access. The server coordinates encrypted changes between devices. When the server is temporarily unavailable, already synchronized vault contents should remain available on the device.

Vault data is designed to be encrypted on the client before it reaches the server. The server is not intended to hold plaintext passwords or the secrets required to decrypt a vault.

CORE IDEAS

A focused password manager.

01

Private vaults

Keep personal information separate. An administrator is not meant to gain automatic cryptographic access to every private vault.

02

Separate spaces

Keep separate vaults for work, personal use, or other collections without granting other users access.

03

Registered devices

Every client device is registered and has its own cryptographic identity. The server knows authorized device identities, not their private keys.

EASY TO SWITCH

Bring your passwords with you.

Import passwords from 1Password, Bitwarden, and LastPass into 127Vaults Desktop. 1Password imports also preserve supported cards, bank accounts, secure notes, identity and passport fields, custom fields, additional websites, SSH key text, and authenticator setup.

Review the import preview for excluded items and fields. Documents, attachments and passkeys are excluded; archived items, tags, favorites and history are not restored. Keep documents in your preferred cloud storage, such as Google Drive, iCloud or OneDrive, and save a link in a URL field here.

ADMINISTRATION

Simple to operate.

127Vaults aims to support user management and private vault use without the complexity of a traditional enterprise password manager. Recovery is intended to be explicit and user designated, rather than blanket administrator access to private vaults.

The same core product is intended for Personal Self-Hosted, Commercial Self-Hosted, and 127Vaults Cloud.
