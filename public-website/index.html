THE APPROACH

Control starts with where
your vault lives.

127Vaults is designed around encrypted client data, registered devices, and a server that coordinates synchronization.

01

Host it yourself

Run the server on infrastructure you control. Access it over a private network and use a secure remote access layer, such as Tailscale or Cloudflare Tunnel.

02

Keep working offline

Authorized devices are designed to retain encrypted local copies of vaults they can access, so a temporary server outage does not block already synchronized passwords.

03

Encrypt before sync

Vault data is designed to be encrypted on your device before synchronization. The server is not intended to hold the secrets needed to decrypt it.

◆

Built for people and small teams. Each user has private vaults; users do not share vault contents.

THE DETAILS

Clear terms, from day one.

How hosting, upgrades, and private vaults work across plans.

01 / PERSONAL

License the version you bought.

A Personal Self-Hosted license is $20 per year for the purchased major version and includes five users. Additional users can be enabled by request at no extra charge. The license does not include hosting or storage. Moving to a later major version is optional and licensed separately.

If the license expires, there is a 30-day read-only period, followed by invalid access until renewal. Encrypted vault data remains intact and renewal restores access.

02 / COMMERCIAL

Stay current during your contract.

Commercial Self-Hosted is $200 per year, paid annually, with a 5- or 10-year commitment. You host and operate the server. Releases during the active contract, including major versions, are included.

03 / CLOUD

Managed infrastructure.

127Vaults Cloud is $30 per user per year, with a 2-year commitment and each annual payment upfront. For 10 users, that is $300 each year. 127Vaults would operate the server.

04 / PRIVACY

Private by default.

Private vaults are part of every proposed plan. Vault contents are not shared between users.
