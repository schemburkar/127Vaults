RELEASE NOTES

Release notes history.

Earlier improvements and fixes across 127Vaults.

← Latest two releases

Version 0.1.19

November 10, 2026 · Personal checkout and guided self-hosted setup.

  • Added the Personal Self-Hosted purchase flow for test-mode verification.
  • Improved guided self-hosted setup, local server administration, and device and audit controls.

Version 0.1.18

October 28, 2026 · Operator navigation, subscription foundations and automated release delivery.

  • Added dedicated operator navigation for access requests, licenses, subscriptions, coupons and release review.
  • Added subscription-payment integration and signed-license renewal support, with payment-failure grace periods and scoped discounts; payment collection remains disabled until merchant configuration.
  • Improved invitation and customer-session handling and added checks for separate public, operator and customer site builds.
  • Added a workstation release workflow covering Windows/Linux packages, standalone installers, protected Cloudflare delivery and verified GitHub release assets.
  • Aligned the published credential-rotation API contract with the implemented request boundaries.

Version 0.1.17

October 27, 2026 · Coordinated packages and Windows/Linux standalone installers.

  • Made extension sign-in listing and filling faster by batching local reads and removing repeated vault scans.
  • Simplified the extension popup with a clear Unlock desktop action, consistent footer icons and a dedicated loading view.
  • Matched saved login websites across www and non-www addresses, including additional saved websites.
  • Improved Desktop keyboard unlock, dismissible search suggestions, action icons, rounded checkboxes and consistent field heights.
  • Fixed false license clock rollback warnings caused by virtual-machine timer drift.
  • Fixed restoring current-schema encrypted backups into a new installation while preserving installation identity checks.
  • Protected enrolled server addresses from development-stack takeovers and added verified local server restart tooling.
  • Made the public website dark by default for new visitors while retaining saved theme choices.
  • Kept the two latest release notes on Downloads and moved earlier notes to a dedicated history page.

Version 0.1.16

October 24, 2026 · Coordinated packages and Windows/Linux standalone installers.

  • Made Password Health a persistent web and desktop detail tab with issue filters, guidance and website change-password links.
  • Added an optional Have I Been Pwned password check using hash prefixes; passwords and complete hashes stay on the device.
  • Added desktop detail-pane resizing with remembered width, keyboard controls and double-click reset.

Version 0.1.15

October 23, 2026 · Coordinated packages and Windows/Linux standalone installers.

  • Prevented overscroll past desktop window edges.
  • Changed desktop button focus rings to gold.
  • Reduced the top spacing in desktop item details.

Version 0.1.13

October 23, 2026 · Desktop, CLI, browser extension, self-hosted server and combined installers.

  • Expanded 1Password imports and improved preservation of authenticator setup across imported items.
  • Improved device approval and request validation, with stronger handling of concurrent trial operations.
  • Prevented stale web saves from completing after a vault is locked.
  • Added per-person trial extensions in the access request desk.
  • Improved recovery of interrupted local release builds.
