DEPLOYMENT

Choose where the server runs.

Self-hosting is the primary deployment model. 127Vaults Cloud is the managed option for customers who do not want to operate their own server.

SELF-HOSTED

Your infrastructure.

You deploy and operate the 127Vaults server on infrastructure you control. Your server stores synchronized encrypted vault data; 127Vaults does not provide hosting or storage under a self-hosted license.

  • You manage the server and its availability
  • Clients are designed for offline access to synchronized vaults
  • Personal and Commercial licenses are available
View self-hosted pricing
127VAULTS CLOUD

Infrastructure we run.

127Vaults operates the server infrastructure. Customers pay per user for the convenience of managed hosting. Cloud does not change the intended client-side vault encryption model.

  • No customer-operated 127Vaults server
  • Offline-first clients are still part of the design
  • 127Vaults manages server operations and updates
View Cloud pricing
PRIVATE NETWORKING

Keep the server private.

For self-hosted remote access, prefer a private networking layer such as Tailscale or Cloudflare Tunnel instead of exposing the password server directly to the public Internet. Secure networking configuration remains the operator's responsibility.

The server primarily coordinates encrypted synchronization. A temporary outage should not block access to vault contents already synchronized to an authorized device.
