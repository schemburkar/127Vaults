LICENSE DETAILS

Two ways to license self-hosting.

Personal: license the version you bought.

A $20 annual license applies to the purchased major version and includes five users. Additional users can be enabled by request at no extra charge. A v1 license can continue to be renewed for v1. Upgrading to a later major version is optional and licensed separately.

On expiration, there is a 30-day read-only grace period. Afterward, access is invalid until renewal. Encrypted vault data remains intact and renewal should restore access.

Commercial: license the current product.

A Commercial Self-Hosted contract costs $200 per year with a 5- or 10-year commitment and annual payments. All versions released during the active contract are included, including major versions.

The customer operates the server. This plan does not include 127Vaults hosting.

Cloud: pay for managed hosting.

Cloud is $30 per vault user per year with a 2-year commitment. Each year's payment is made upfront. Ten vault users would cost $300 per year, not $600 paid at once.

Every Cloud tenant uses the same per-user price. It can start with one vault user and add seats later. The person who manages billing can be different from the vault user and does not consume a vault seat unless they also enroll in the vault.

127Vaults operates the infrastructure. The core security architecture is intended to match self-hosted plans.
