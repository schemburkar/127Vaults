Checking your client download link…

Three different things

  • Connection file: tells Desktop which server to trust. Import it only from your administrator.
  • Account invitation: lets a new user create their vault account on that server.
  • Device approval: confirms this computer from an already trusted device after account setup.

This download link supplies client packages only. It cannot open billing, issue a license or install a server.

Install on this computer

Recommended: run the combined installer, choose Join an existing server, and supply this joining link when it asks for downloads. Import the server connection file your administrator shared. You can also install Desktop directly.
