# 127Vaults licensing policy

Decision revised 2026-10-18. This policy is not a license grant.

Use an original 127Vaults Source-Available License. Local, personal, internal
and non-production execution require an express license.

Permit source inspection only. Compiling, installing, running, modifying and
redistributing require separate written permission. Operational use requires a
paid license unless the licensor expressly authorizes a scoped internal test or
trial in writing. Third-party licenses, repository-host permissions and rights
that applicable law does not permit restricting remain unaffected.

See docs/legal/source-available-license-draft.md for proposed wording. It is a
review draft, not an adopted LICENSE. Obtain qualified legal review before use.
This is proprietary source-available software, not OSI open-source software.

The previously discussed four-year AGPL-3.0-only conversion must be finalized
separately before publication. This policy grants no conversion and sets no date.
If retained, compliant AGPL use of converted versions cannot require payment;
commercial terms would remain an alternative. Existing grants cannot be withdrawn
by changing repository text or Git history.

The proposed licensor remains Shubhan Chemburkar, subject to ownership review.
Commercial agreements must specify versions, users/installations, scope, payment,
term, renewal, modification, redistribution, support, liability and termination.
Outside contributions require sufficient written licensing rights. Trademarks
remain separate. License state and cryptographic key state remain separate as
specified in ADR-0004.

Current access is restricted internal testing, as confirmed by the owner. Keep
private development history private. Before public release, review dependencies,
ownership, source and history; adopt the reviewed license and agreements; and
finalize any conversion commitment. Create the public repository from a reviewed
source export with the adopted license in its first root commit. Do not assume a
new license retroactively changes permissions on previously distributed copies.
