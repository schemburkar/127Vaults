# Browser extension backlog

Updated 2026-10-06. Chrome/Edge extension scope is an **offline-capable, read-only autofill connector**. It can use web, desktop or CLI; offline fill requires a hydrated installed desktop/CLI replica. It is experimental and not a supported release. See [Batch 13](implementation-batches.md#batch-13--browser-extension), the [offline-client decision](../adr/0018-offline-replicas-causal-sync-and-server-topology.md), the [locking decision](../adr/0019-client-locking-and-secret-exposure.md), the [connector run guide](../../apps/extension/README.md), and the [public extension walkthrough](../../public-website/index.html#extension).

First extension slice: connect to an active web, desktop or CLI client; use a previously hydrated installed desktop/CLI replica for offline unlock; search/select a login; fill username/password only after a user action; and lock. The extension does not own or write a separate replica. It must fill when the server and web tab are unavailable if a desktop/CLI replica is installed, and clearly show stale/offline state. Editing is excluded from the extension, not deferred to a later slice.
