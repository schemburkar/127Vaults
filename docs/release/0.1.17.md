# 127Vaults 0.1.17

Released October 27, 2026.

- Made extension sign-in listing and filling faster by batching authenticated local reads, removing repeated vault scans and reducing connector waits.
- Simplified locked and unlocked extension views, moved source selection into the footer, and separated loading from stale screen content.
- Matched www and non-www login addresses, including explicitly saved additional websites, while retaining site and port checks before fill.
- Improved Desktop keyboard unlock, dismissible search suggestions, detail action icons, rounded checkboxes and field alignment.
- Fixed false license clock rollback warnings caused by virtual-machine elapsed-time drift, retaining detection of actual backward clock changes.
- Fixed the installer restore guard to accept current-schema encrypted backups while retaining installation and database checks.
- Protected enrolled server addresses and histories from development-stack takeovers and added pinned local restart verification.
- Made the public website dark by default for first-time visitors while preserving saved preferences.
- Added release-notes history, with only the latest two releases shown on Downloads.

Includes coordinated Desktop and CLI packages for Windows/Linux, the Chromium extension, self-hosted server/web, and standalone Windows/Linux installers. Packages remain available through approved private download links; the standalone installer archives and SHA-256 checksums are attached to this GitHub release under the repository's existing visibility.

Back up existing installations and follow the included upgrade instructions. Update Desktop and the extension together, then unlock Desktop and reload the extension to use the faster local connector.
