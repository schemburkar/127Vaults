# 127Vaults 0.1.16

Released October 24, 2026.

- Made Password Health a persistent tab in the web and desktop detail pane, keeping the item list visible.
- Added issue filters for short, predictable, reused and breached passwords, with guidance and links to change passwords on their websites.
- Added an optional Have I Been Pwned password check that sends only hash prefixes and keeps passwords and complete hashes on the device.
- Added a draggable desktop divider with remembered detail-pane width, keyboard adjustment and double-click reset.

Includes coordinated desktop and CLI packages for Windows/Linux, the Chromium extension, self-hosted server/web, and combined installers. Installers and checksums are delivered through approved private download links; the standalone installer archives and checksums are also attached below.

Back up existing installations and follow the upgrade instructions included with the packages.
