# 127Vaults 0.1.13

Released October 23, 2026.

- Expanded 1Password imports and improved preservation of authenticator setup.
- Improved device approval, request validation and concurrent trial operations.
- Prevented stale web saves from completing after vault lock.
- Added per-person trial extensions in the access request desk.
- Improved recovery of interrupted local release builds.

Includes coordinated desktop and CLI packages for Windows/Linux, the Chromium extension, self-hosted server/web, and combined installers. Installers and checksums are delivered through approved private download links; no package assets are attached to this GitHub release.

Back up existing installations and follow the upgrade instructions included with the packages.
