# 127Vaults 0.1.18

Released October 28, 2026.

- Added dedicated operator navigation for access requests, licenses, subscriptions, coupons and release review.
- Added subscription-payment integration and signed-license renewal support, with payment-failure grace periods and scoped discounts; payment collection remains disabled until merchant configuration.
- Improved invitation and customer-session handling and added checks for separate public, operator and customer site builds.
- Added a workstation release workflow covering Windows/Linux packages, standalone installers, protected Cloudflare delivery and verified GitHub release assets.
- Aligned the published credential-rotation API contract with the implemented request boundaries.

Includes coordinated Desktop and CLI packages for Windows/Linux, the Chromium extension, self-hosted server/web, and standalone Windows/Linux installers. Packages remain available through approved private download links; the standalone installer archives and SHA-256 checksums are attached to this GitHub release under the repository's existing visibility.

The public website continues to offer Request access. Dodo payment collection is not enabled by this release. Separate production admin and customer domains remain a deployment migration.

Back up existing installations and follow the included upgrade instructions.
